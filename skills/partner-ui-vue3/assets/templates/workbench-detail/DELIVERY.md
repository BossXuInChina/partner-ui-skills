# 协议详情交付说明

## 保留与允许差异

源 HTML 只读保留。SFC 保留业务文案、组件布局与交互；按任务约定移除底部「页面说明」演示区、演示注释、页头「（演示数据）」及操作提示「（演示）」后缀。这些演示说明的移除是视觉比对的允许差异。`pui-*` 布局类替换为共享 `feature-*` 等价布局类，不修改组件内部样式。

原示例数据已迁至 `mocks/`，实际页面要求显式 API 注入。新增真实加载/错误/空数据状态和重试入口用于网络失败；成功数据状态仍按原模板布局渲染。服务响应、导航与导出能力必须由集成方实现。
