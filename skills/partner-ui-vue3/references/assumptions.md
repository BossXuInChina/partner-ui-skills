## 当前工具链差异

技术栈默认值及 harness engines 目前仍写 Node ≥22.12；实际 pnpm 11.22.0 启动门槛为 Node ≥22.13。完整工程目前使用 22.13+，该声明差异待工具链统一项解决。脚本单独在 22.12 运行不证明该版本能启动 pnpm。
