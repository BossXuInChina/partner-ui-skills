# AI UI 问题交接

消费页面负责 `.partner-ai` 挂载、宿主高度、滚动/遮挡、公共 props/slots、可达性和错误日志；这些保留在本次页面复查。

涉及 AI 库 Token 引用链、组件/Demo/总览同步、流式/停止/历史保留、库内 Markdown 级联或包编译差异时，交给独立的 `partner-ai-ui-global-review`。只在该技能可用且本次范围需要时读取其入口；页面审查不自动授权修改 AI 源仓。

交接附：实际包版本与 release 元数据、源码/产物是否可对应、宿主路由与宽度/状态、复现步骤、截图区域、计算样式与可疑宿主选择器、日志、已做验证、要求维护方核查的问题。包含未提交源变更的包必须如实标记，旧锁参考不能用来断言新增 API 不存在。

组件源仓只读或技能不可用时，在报告标记“交接待执行”，保留证据，不复制库规则或称全局复查已完成。库级修复和重打包须在对应维护任务处理；消费方不以 deep CSS/important 修补。
