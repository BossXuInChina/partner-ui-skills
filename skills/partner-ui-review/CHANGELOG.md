# Changelog

## 0.1.3 · 2026-11-06

- 以分页展开菜单继承 16px/normal、快捷应用窄容器逐字折行为真实回归。
- 支持 states 进入真实交互态，按状态保存证据；textContracts 校验完整字阶、字体族、文本行数与项目边界。
- 区分宿主字体基线、组件公开文字合同及业务项目的响应式排版责任。

## 0.1.2 · 2026-11-06

- 以订单页签贴住查询区的真实漏检为回归：自动发现页面容器内的相邻组件内容关系，0px 不再因数值合法而静默通过。
- 区分自动候选与明确规范契约；正式组件内部不套用外部关系推断。
- 用户标注的路由/状态/宽度必须进入测量；项目契约持久保存，记录修复前失败与修复后通过。

## 0.1.1 · 2026-11-06

- 区分正式组件内部契约与页面/业务卡片/slot 组合规范，嵌套组件恢复独立归属。
- 使用真实包样式和最近边界识别 AI 组件；Typed OM 正确处理 logical auto 及其覆盖关系。
- 新增 R9 语义布局契约，检查合法 Token 用错位置及多层 margin/gap 的实际叠加；违规使测量失败，缺少证据明确未验证。
- 卡片例外必须有规范依据；补充真实浏览器回归和试跑证据。

## 0.1.0 · 2026-11-06

- 新增页面复查流程、共享静态引擎、双宽截图、浏览器测量与设计图对照。
- 有限图标名称支持冻结映射和显式兜底；保持未知表达式警告及非法名称错误。
- R8 需要可比独立样本，证据不足保留未验证，不把计算值差异当覆盖证明。
- Workbench 新包来源校验阻塞，保留原锁；候选能力与锁升级验收分别报告。
