# 画布交互与离线交付

用于制作或维护画布，不用于只读审查。以下行为已由 `assets/canvas-host.js` 实现，并由 `scripts/test_canvas_browser.mjs` 回归（图片加载、节点不重叠、连线数量、指针锚定缩放、空白拖动、七区面板、标签高亮与清除、浮层与焦点返回、连接跳转、关闭、导出一致、手机宽度、无网络请求）；改共享资源时须保持全部通过。右栏的唯一结构与默认交互以 [统一画布与右侧面板合同](canvas-template.md) 和内置 inspector.js/CSS 为准；本文件补充全画布行为，不授权另写右栏变体。

- 截图节点显示页面、角色和来源；关联线区分明确连接与只确认所属区域。没有被画出目标的入口在动作清单保留未知，不创建虚假目标节点。
- 点击页面显示区块、原图事实、参考状态、组件候选、确定配置、缺口、范围与验收。标签 hover 和键盘 focus 联动到该页参考区域；click 可看放大截图。区分组件参考区域与整区范围；待评审项定位时同时显示排除状态。
- 初始布局、图片加载后、角色切换后的节点均不得互相覆盖。按图片实际尺寸排布，加入区块或修复裁剪后重新核验；固定位置是允许的，节点拖动按用户需要实现。
- 鼠标/触控板缩放保持指针下同一内容点稳定。缩放计算必须与 transform-origin 一致；测试多个位置的前后坐标漂移，而非只读缩放百分比。空白拖动、适应全图、关联定位和浮层关闭也检查。
- hover 不应使右栏跳动；目标不在画布可视范围时可平移定位。颜色配合文字表达纳入、组件优先和待评审排除，不仅靠颜色。
- 模块化源代码可按场景组织；数据间使用固定 ID。纯 HTML 交付应内嵌本地依赖、图片和样式，保留适用的开源许可；在 file:// 实测，确认无必要的网络请求。预览服务器只是开发工具，不是离线交付依赖。
- 导出使用画布同一数据模型，包含事实来源、组件前置工作与明确排除项。截图不随 JSON 附带时明确说明要配合内嵌截图的 HTML，不能声称 JSON 已独立包含视觉证据。

浏览器验证关注可见结果：图片真的加载，标签对应正确页面/区块，移动指针后高亮消失或符合焦点行为，点击能查看原图，导出能解析，review 不泄漏到 included。功能通过后仍需按原图做语义核对与必要的视觉检查。
