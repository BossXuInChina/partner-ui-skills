# 统一画布与右侧面板合同 v1

用于制作或更新需求画布。报告模式不强制生成 UI。用户明确另选形式时采用其形式；本工作流默认全面沿用已经确认的首页体验，不能自行降级成截图阅读器。

## 必须复用的实现

新场景由 `scripts/build_canvas.py` 生成，自动内嵌 `assets/page-review.js`（页级范围与四类摘要）、`assets/inspector.js` + `inspector.css`（完整右栏）、`assets/canvas-host.js` + `canvas-host.css`（左侧视图/目录、节点与连线、缩放平移、原图浮层、导出）。不能运行时依赖 Skill 路径、CDN 或服务器。

旧数据结构通过适配器转为 `design-evidence/1` 后使用同一面板；不要各场景重写一套 innerHTML，再声称结构等价。原有用户认可的首页保留业务语义，迁移只改适配与面板接入，不擅自改写事实。除用户明确要求替换交互框架外，不提供另造精简右栏的路径。

只有数据可因场景不同而改变，信息架构、顺序、视觉层级、操作和缺项表达保持一致。摘要渲染器不能独立充当完整面板。

## 固定右栏结构

顺序与默认状态如下；没有内容时显示对应缺项，不删除区域。

| 顺序 | 区域 | 固定内容与默认状态 |
|---|---|---|
| 1 | 页面身份 | 页面标题、角色、说明、关闭详情；始终展开 |
| 2 | 原图证据 | 裁剪缩略图、点击放大、来源、原图与裁剪像素；说明像素不等于视口 |
| 3 | 本次还原边界 | 原则及三类互斥工作项数量；始终展开 |
| 4 | 需求完整性 | 原图已见、能力与组合线索、业务待确认、还原检查；四组均展开 |
| 5 | 页面结构与组件 | 区块标题与范围、原图事实、组件标签、缺口/工作项；每个区块都保留 |
| 5a | 字段、状态与验收 | 每区块折叠详情：字段、截图状态与参考数据、操作与关系、待确认、还原检查、原图定位按钮 |
| 5b | 组件公开契约与实例配置 | 每区块折叠详情：公开符号、版本、资格、契约来源、公开 API 索引与确定 Props、Slots、状态绑定、事件动作、配置缺项 |
| 6 | 页面连接 | 来自/去往、触发文字、证据强度、目标定位按钮；无连接明确说明，未知入口保留在动作中 |
| 7 | 生成前待补充 | 设计尺寸/响应式、真实接口/权限/路由、图外状态、证据及 review 排除限制 |

不能将第 6/7 区域省掉，也不能把 5a/5b 退化成组件名标签。整个右栏独立滚动，查看长文不推动画布。使用内置 CSS 的字号、留白、蓝色边界卡、暖色完整性卡和工作项状态；只通过已有 CSS 变量统一换肤，不对单场景覆盖内部样式。桌面宿主为右栏预留 360px，小屏以同一面板抽屉承载，不删减栏目或让面板和画布内容互相遮住。宿主的左侧场景/页面选择、中央节点与连线、顶部适应画布/缩放/导出也沿用确认样板。

### 内容与计数

- 三类分别只计 `lane=reuse`、`component-work`、`review`，以本页全部工作项 ID 为依据。`inPageRestoration=true` 包含前两类，不能拿它当第一类。0 表示当前没有登记该类项，不能声称没有缺口。
- `原图已见` 写本页具体事实、可读字段与默认状态，不用“以原图为准”充数。`unknowns` 仅放图和契约无法确定的事项；`acceptance` 写可观察结果。图外加载、失败和空态标“建议补充，非原图事实”。
- 缺省可能指漏识别内容、组合能力或默认状态，按对话检查三者；不能只显示空态组件。
- 工作项、候选组件和原图事实分开。混合区块可同时有基础组件复用与待评审视觉，局部明确排除；不可通过“完全照原图”把 review 又加回验收。
- 面板总是显示缺项状态，不等于工作完成。清晰可读而未识别、实例配置未核实等仍须继续处理；不能靠默认缺项提示通过内容审查。

## 统一交互

| 触发 | 结果 |
|---|---|
| 点击节点/左侧页面 | 同一页面 ID 同步节点选中与右栏；右栏滚动回顶部，旧红框清除 |
| hover 或键盘 focus 组件/工作项标签 | 高亮对应截图范围；缺少组件级区域时明确为整区近似范围；无区域只定位整页 |
| 鼠标离开/失焦 | 清除对应高亮；当前仍有键盘焦点时保留焦点高亮 |
| 点击标签或区块原图按钮 | 放大当前截图并携带同一范围；review 必须带“待评审 · 排除还原”文字 |
| 原图缩略图 | 打开整页；浮层支持 Escape/关闭按钮/空白关闭，关闭后焦点回到触发按钮 |
| 点击页面连接 | 同步选中目标、更新右栏、切换目标所属分组并定位画布；未知目标不造按钮 |
| 关闭详情 | 清除选择与红框，恢复统一未选择态，宿主将焦点回到来源节点或页面项；不删除节点或重置画布视角 |
| 切换场景/重新载入数据 | 清除旧选择、hover 和监听器，避免旧状态串页或重复触发 |
| 导出 | 使用同一 manifest，包含事实、字段、配置缺项、连接、全部范围和明确排除；说明图片是否随 JSON |

hover 不改变右栏滚动位置，目标不在画布可视区时宿主只平移定位。节点图片载入及场景切换后不得覆盖；鼠标/触控板缩放始终保持指针内容点。只读画布可以固定节点位置，不假装支持节点拖动。

## 接入接口

```js
const inspector = DesignCanvasInspector.create({
  container: document.querySelector('#detail'),
  manifest,
  resolveImage: page => page.image, // 打包时嵌入的裁剪截图，或随附相对路径
  onSelect: ({ pageId }) => canvas.selectOnly(pageId),
  onHighlight: detail => canvas.highlight(detail),
  onClearHighlight: () => canvas.clearHighlight(),
  onPreview: detail => preview.open(detail),
  onNavigate: ({ pageId }) => canvas.showGroupAndFocus(pageId),
  onClose: () => canvas.clearSelection()
});
inspector.select(pageId);
// 场景切换：inspector.clear()；载入新 manifest：先 inspector.destroy() 再创建。
```

`assets/canvas-host.js` 的 `DesignCanvasHost.mount({root, manifest, images})` 已按本节接好全部回调，构建出的画布直接使用它；上例仅说明自行嵌入其他宿主时的接法。所有回调均须接入真实行为，不能传空函数来通过检查。面板负责内部渲染、折叠、当前页与清理；宿主负责画布选中/定位、浮层及全局导出。`onNavigate` 调用时目标右栏已经选中，宿主不要再次替换右栏 DOM。

定位事件载荷包含 `pageId/sectionId/mappingId/workItemId/region/precision/lane/label`。优先 `mapping.evidence.region` 或工作项区域，其次区块区域，再降级整页；ID 固定且语义明确，不依赖数组下标。回调收到 region=null 时不能继续显示上一个红框。

面板数据不完整时显示明确错误态并抛出错误，不得静默渲染“0 项/已完整”。默认未选择态、缺失数据态和正常详情均有统一表现。内置模板不会验证截图识别或业务事实。

## 场景交付与验证

每场景一个目录，包含单文件 HTML、需求 JSON、场景报告/索引、模块化源码及许可；顶层索引只导航。旧底稿明确标旧版，不作为当前画布入口。来源绝对路径可记录，但不能是唯一可交接证据。

运行数据和面板 DOM 回归后，仍需实际浏览器验证：所有页面七个区域及每区块两类折叠详情存在且可用；三类计数一致；焦点、hover、清除、区域放大、来去连接、关闭/切换、重复选择和导出行为正确。采用 `data-inspector-version/part`、`data-page-scope`、`data-page-completeness`、`data-review-group` 和 section/mapping/workItem ID 定位，不只检查标题文字。

共享 DOM 测试先在 Skill 根目录 `npm install`，再运行 `node scripts/test_inspector.mjs`（或用 `--dom-module` 指定 happy-dom），加 `--manifest /absolute/path/manifest.json` 逐页检查本次真实数据，而不是只跑合成样例。DOM 测试只验证渲染、事件与状态，不证明实际布局、图片加载或像素定位；实际浏览器行为用 `node scripts/test_canvas_browser.mjs --html <画布> --manifest <manifest>` 检查。离线与浏览器限制按工具规则处理；不能绕过拒绝，也不能用结构检查替代未完成的视觉/交互验收。修复一处不应停止其他可继续的内容与组件审查。

可运行 `python3 scripts/build_inspector_demo.py /absolute/output/统一右侧面板-模板示例.html` 查看自包含的合成示例，检验结构、折叠、双向关系、关闭/选择、标签区域放大与导出。示例不是业务模板数据或完整无限画布，不得拿合成事实生成业务页面。
